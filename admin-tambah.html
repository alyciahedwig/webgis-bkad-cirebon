PENGELOLAAN DATA

Tambah Data Aset

Impor data bidang tanah aset dari GeoJSON atau Shapefile dalam format ZIP. Periksa sistem koordinat, pemetaan atribut, dan hasil pratinjau sebelum data disimpan ke basis data.

01

Unggah data spasial

Gunakan GeoJSON atau Shapefile ZIP. Untuk SHP berproyeksi, sertakan file .prj agar sistem koordinat dapat dibaca dengan benar.

ATAU
02

Sistem koordinat sumber

Pilih sistem koordinat yang digunakan oleh geometri sumber. Data akan disesuaikan ke sistem koordinat tabel aset saat disimpan.

Terpilih: WGS 84 (EPSG:4326)
03

Pemetaan atribut

Cocokkan kolom pada file sumber dengan atribut WebGIS. ID Barang dan NUB wajib tersedia.

Dihitung otomatis dari geometri
i

Nilai luas_m2 tidak diambil sebagai nilai final dari file sumber. Luas dihitung ulang berdasarkan geometri ketika data disimpan.

04

Penanganan NUB yang sudah tersedia

Tentukan tindakan apabila NUB pada data baru sudah ditemukan di basis data.
